# Design: 243 Round 61's builds (331, 332, 334, 336)

## Problem

Round 61 ruled four things wave 14 built as guesses: the /open-source
group heading (331, #831), the parsed card's "Change" after a move (332,
#832), the badged runs row's gap (336, #839) and the pill kinds that had
none (334, #835). This lane builds them. It stacks on design 241's branch
(`ParsedCard`, the pill constants) and rebases once that merges.

## Approach

**336.** `RunList`'s badged row: the badge line sits 16 under the mono
line (`gap-1` plus `mt-3`) and the row pads 12 below. The ruling's 102
is on the board's line boxes; the type's own make it about 106.

**332.** `ParsedCard`'s `TimeButton` takes the verb: "Change" at rest,
"Changed" after a move, in the same slot. The " ·" goes.

**331.** `OpenSourcePage` drops the "Projects" h3. A licence group's h2
reads "Projects under the {licence}", from a table of full licence names
in `open-source.ts`. The names are wording on a legal page, so the table
waits for the owner's answer.

**334.** New constants in `src/ui/form.tsx`, and every site moves onto
one:

- `ACTION_PILL` (334.1): the top bar's launcher, the signed-out bar's
  and Landing's Request access, the invite card's pill, the profile's Log
  a run and the shade sheet's Use this, which loses its display caps.
- `CHIP` (334.2): the name row's suggestions and a piece's "Name it".
  `MoreDisclosure` becomes an underlined text button with the pack's
  `forward` glyph, as /open-source's disclosures are (R58·290).
- `INK_PILL_INLINE` and `SECONDARY_PILL_INLINE` (334.3): the ruled ink
  and hairline pills without 167.2's column width rule, for Follow and
  Following beside a name. Both labels share one grid cell, so the pill
  is one width in both states.
- `ICON_BUTTON` (334.4): the pager's arrows and a photo's delete, the
  glyph at 20.

The pill lint's per-file exemptions for these files are the owner's edit
(`eslint.config.js`); the lane asks for it and deletes nothing itself
until granted.
