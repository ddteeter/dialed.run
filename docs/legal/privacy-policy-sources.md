# Privacy policy: where each claim comes from

`privacy-policy.md` is only true while the code below stays as it is. This
file maps each claim to the code or config that makes it true, as of
`origin/main` at `356de7f` (2026-10-11), re-checked against `310f7ba3`
(2026-10-21, after lanes C1–C4 and C12–C15 merged; C6 read from PR #206).
Line numbers below are as of `310f7ba3`. **A change to any file named here
should come with a check of the matching policy line**, and a change to the
policy should come with a check of the code.

Paths are relative to the repo root. `better-auth` paths are inside
`node_modules` at the pinned version (1.7.2). Web sources give the date
they were read.

The 2026-09-29 "Drift since be70c6d" report that used to close this file
has been applied to the policy text (2026-10-11 reconciliation); the rows
below are the current evidence.
