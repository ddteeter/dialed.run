3 · The call Must always return something. "I can't help" is never an acceptable output — degrade the confidence, not the answer.
CONDITIONBEHAVIOURCOPY DIRECTION

Conditions outside all coverageExtrapolate from nearest band, widen the hedge, ask for a verdict afterwards."First time I've seen you at 12°. Here's my read — tell me how it went."
Forecast unavailableFall back to climate normals for that date and location; label it clearly."No forecast yet — this is a typical late-October morning here."
Best piece is in the washRecommend the second-best and say why. Requires laundry state — the reason it's worth building."Half-zip is in the wash. The green crew is a degree warmer but close enough."
Closet genuinely lacks anything suitableRecommend the closest thing they own, then name the gap honestly. Links to gear gaps (J)."Nothing in your closet really covers 8° and windy. Closest is the merino base — expect to be cold."

Run is more than 7 days outShow climate normals with an explicit low-confidence band; offer a reminder to re-run the call closer to the day."Too far out for a real forecast. Ask me again Thursday."
4 · Empty states Every one names the single next action, and none of them are illustrations with a shrug.
CLOSET · 0 PIECES

"Nothing in here yet. Add the five things you actually reach for — the rest can wait."

Single CTA to camera. Never a tour.
FEED · 0 FOLLOWS

Don't show an empty feed at all — land on "Your conditions" (E2) and put Discovery one tap away.

The Following tab shows a follow prompt only if the user selects it deliberately.
YOUR CONDITIONS · NO MATCHES

"Nobody near you has logged 8° and windy yet. You'll be the first."

Widen the match radius before declaring empty. Frames scarcity as contribution.
RUNS · 0 LOGGED

"Drop in a GPX and we'll figure out the weather for you."

Explain where a GPX comes from — most runners have never exported one.
SAVED KITS · 0

"Kits are outfits you'd wear again. Save one from a call or from a run that worked."

Teaches the concept at the moment it's missing.
GEAR GAPS · NONE FOUND

"No holes worth mentioning. Your closet covers everything you actually run in."

A valid, good state. Do not invent a gap to fill the screen.
GARMENT · 0 RUNS

Show the attribute-estimated range with [UNTESTED] instead of an empty chart.

Estimated data beats no data, as long as it's labelled.
CLOSET · ALL GENERIC

"5 of 8 pieces are still generic — name the ones you reach for."

A quiet header line, never a blocking prompt or a modal. Generic pieces work; named ones just learn faster.
POST · 0 COMMENTS

Nothing. No "be the first to comment" prompt.

Silence is not a problem to solve on a reference feed.
5 · System states Applies to every screen. Define once, use everywhere.
STATETREATMENTNOTES
LoadingSkeletons in chalk at the real content's dimensions. No spinners.The call is the one place a wait feels earned — it's thinking. That treatment arrives with the call.
OfflineV1 is online-required. Every write fails inline with a retry; nothing queues. Cached reads of the closet are the only offline affordance.Runners open this app at 5am in a basement, so full offline support is a real need — it's the PWA epic, deliberately deferred rather than forgotten.
ErrorInline at the point of failure, never a full-screen takeover. Always one retry and one escape.Voice: own it plainly. No apology paragraphs, no error codes in the primary line.
Stale dataForecasts older than 30 minutes show their age in mono. Re-fetch on foreground.A stale forecast that looks fresh is worse than no forecast.
Permissions deniedLocation denied → manual city entry everywhere. Camera denied → tap-list garment entry (O3 pattern).No feature is permission-gated into uselessness. Every one has a typed fallback.
Units°F/°C and mi/km set at onboarding from locale, changeable in Settings. Every stored value is metric.Temperature bands are the core data model — get the unit boundary right once.
Link enrichmentName and brand land from the URL immediately; fabric, weight and image fill in async. Failure replaces the link row in place with a manual-entry offer.Never blocks Add. Everything pulled is an editable claim, not a locked fact.
Ownership proofSocial proof on kit rows is derived from public posts only — "worn by 12 runners this month". Drop the line when the count is small.Never counts from private closets. Same rule anywhere ownership numbers appear.
6 · Verdict lexicon Five states, locked. These exact strings ship in the UI, the data model, and the copy.
−2way cold
−1a bit cold
0dialed
+1a bit warm
+2way warm
CASING

Lowercase in prose, uppercase in mono chips and badges. Bracket notation unchanged: [DIALED].

NEVER SAY

"too cold" / "too warm" — superseded by the five-state wording. No numeric scores in the UI; the ±2 values are storage only.

WHY FIVE

"A bit cold" and "way cold" call for different corrections — a layer versus a rethink. Three states can't express that, and the model needs it.

7 · What to build first
MILESTONE 1 · V1 · PROVE THE LOOP

Onboarding (O1, P2, P2.5, P3), add garment (F + enrichment), log a run (A1–A3 + Q), closet (C), profile (G), Call teaser (K), settings (N), notifications (M), Strava trigger (L), E2-lite consensus.

No call, no kits, no comments. The bet: logging plus visible progress keeps a runner for a season.
MILESTONE 2 · THE CALL EPIC

B1–B2, saved kits, photo-read garment capture (O2 pattern), laundry state, cohort math, "calls dialed" accuracy.

Gated on the hand-validation result — don't ship a call you haven't proven beats a dressing chart. Laundry lands here: it matters when the answer is "that's in the wash."
MILESTONE 3 · OPEN IT UP

Full E2, comments and moderation, discovery (I), "try this kit", offset-translation on profiles, PWA offline.

Comments don't ship before reporting and blocking do.
MILESTONE 4 · EARN THE COMMERCE

Gear gaps (J), retirement suggestions, cohort ownership data.

Gated behind 15+ verdicts per user. Never before the data justifies it.
Before any of this

Validate the recommendation by hand. Twenty runners, their closets and ten recent runs each, in a spreadsheet — generate calls against held-out runs and measure the hit rate.

If a human with full data can't beat a generic dressing chart, no amount of app solves it. This is a week of work and it de-risks the entire build.
