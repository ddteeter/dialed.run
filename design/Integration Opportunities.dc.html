Integration opportunities  /  where the record lives outside the appdialed.run

Your blog says how it fits. dialed.run says how it did.

A garment's record (runs, the conditions it was worn in, the verdicts) published as data, so other sites can render it in their own styling. Each one links back to a dialed.run conditions guide, which is where the search value comes from. biglongrun.com is the first and reference integration.

AT REVIEW · LIFETIMESame split as Strava. At Review is the record up to the post's publish date (?asOf=2026-03-04), so the numbers match what the review says. Lifetime grows with every rebuild.
BY CONDITIONS · THE LINK THAT MATTERSEach band is a normal followed link to dialed.run/what-to-wear/{band}. A band whose guide isn't published yet (fewer than 5 runners) is rendered as plain text, not a link, so a link never lands on a missing page.
VERDICTS · THE BLOG'S WORDSThe feed returns the five verdict keys (way_cold … way_warm) on rows and folded to cold · dialed · warm in totals, and biglongrun picks the words and colours. The block never uses dialed.run's hues or type. It's credited in the footer, the same way Strava is.
RUN ROWS · LINK TO DIALED.RUNEach date links to the entry on dialed.run (app.dialed.run/feed/entry/{id}). Signed-out readers get the Round 30 #5 landing, which shows nothing of the entry (D-58), then the pitch and Log in / Request an invite. After signing in, they land on the entry. The read-only public view first drawn here is withdrawn.
UNIT PREFERENCESEvery temperature comes in both °F and °C, so biglongrun's existing unit switch drives it with no second request.

SHARED ONLY BY DEFAULTThe token decides (Round 30 #6). For a token set to shared entries only, PRIVATE entries never appear, in the totals or the rows. A token set to include private entries counts them too, but row links to private entries are left empty, since nobody else can open them anyway. A blog token should be shared-only.
NO TIME, NO PLACEThe feed carries dates only, with no start time and no location. Strava links show what the owner has already chosen to show there.
UNPUBLISHED = 404If a piece is unpublished, deleted or its key is revoked, the endpoint returns 404. The Astro component then renders nothing and logs a build warning, and the page still builds.
RETIRED KEEPS ITS RECORDA retired piece stays published. Lifetime stops growing and the feed adds "retired": "2026-05-01".
EXPORT LISTS ITU1 export gains published.csv (piece, published_at, key last used).
03 · Turning it onA personal API token from Settings › Account, drawn in Round 30 #6. The per-piece publish toggle first drawn here is dropped, so the token is the only switch. The blog asks for a piece by its id, which is shown on the piece's page and goes in the review's frontmatter (dialedPiece: pc_8f2c41a9) next to the Strava gear id. Revoking the token removes the block on the next build, through the 404 rule in 02.
04 · Other openingsRanked by how much attention each brings, against how much it costs to build. None of these are committed. Marked for a decision.
Shoe reviews tooV1 · SAME BLOCKIf shoes are in the closet, the same endpoint works for them. The Nimbus 27 review would gain "Rain 4 · slippy after fresh rain" as data next to what the review says about it.
Kit line on the Strava activityAFTER LAUNCH · BIGGEST REACHOpt-in. After a verdict, dialed.run appends one line to the activity description: "41°F damp · Dialed · kit via dialed.run". Every follower sees it. It needs Strava's write scope and a brand check with Strava.
biglongrun /compareAFTER LAUNCHCompare two jackets by band: which one was dialed more often at 32–41°F. It reads the same feed and needs no new endpoint.
Other runners' sitesLATER · OWNER-ONLY FIRSTIn v1 only the owner makes tokens (Round 30 #6 is built after the friends stage). Opening it to every runner adds rate limits, abuse handling and a Desk view of who has keys. Worth doing once biglongrun shows whether it brings traffic.
Guides link to reviewsV1 · THE RETURN LINKWhen a published piece's band has a guide, the guide shows "Reviewed on biglongrun" against that piece. Links in both directions, between sites you own, about the same garment.
