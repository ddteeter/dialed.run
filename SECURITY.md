# Security

## Reporting a problem

Please report a security problem privately, through
[GitHub's private vulnerability reporting](https://github.com/ddteeter/dialed.run/security/advisories/new)
(the **Report a vulnerability** button on this repository's Security tab).
Only the maintainer sees the report.

Please don't open a public issue, pull request or discussion that describes
an unfixed problem.

Say what you found, where, and how to reproduce it. This is a one-person
project: replies come in that report, as soon as time allows.

## Scope

The code in this repository and the app it deploys. A problem in a
dependency is best reported to that project; tell us too if it affects
this app.
